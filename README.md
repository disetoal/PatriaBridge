# PatriaBridge

PatriaBridge is a Geyser extension I made for PatriaCraft to improve compatibility between Java and Bedrock.

The main goal of the project is to handle custom content better when Bedrock players join the server, especially things that normally don't translate correctly through Geyser.

### What I worked on

- Java to Bedrock entity mappings
- Custom entity handling
- Runtime entity bindings
- Geyser extension API integration
- Testing compatibility between Java and Bedrock clients

### Project info

- Geyser Extension API: 2.11.0
- Version: 3.0.0-beta.15
- Java

This is one of the tools I use in the PatriaCraft server project. It is still being improved as I test more custom content.

> Source code and compiled builds are private. This repository is only here to show the project and the type of work I have done.
